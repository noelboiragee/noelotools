How to Calculate Percentages: Simple Examples

Learn how to find a percentage, calculate a percentage of a number and work out percentage change.

NoeloTools Editorial•5 min read

Percentages express a value as parts per hundred. They are used for discounts, tax, marks, budgets and comparisons. Once you know a few basic formulas, many percentage questions become straightforward.

Find a percentage of a number

Convert the percentage to a decimal and multiply. For example, 15% of 200 is 0.15 × 200 = 30.

Find what percentage one number is of another

Divide the part by the total, then multiply by 100. If 30 out of 200 items are selected, the share is (30 ÷ 200) × 100 = 15%.

Calculate percentage increase or decrease

Subtract the original value from the new value, divide the difference by the original value and multiply by 100. A positive result indicates an increase; a negative result indicates a decrease.

Avoid a common mistake

For percentage change, the original value is the reference point. Dividing by the new value instead will produce a different and usually incorrect result for the usual percentage-change question.

Use a calculator to check

The Percentage Calculator can help with common percentage calculations. Enter the values carefully and check whether the question asks for a percentage of a value, a ratio or a percentage change.

Practical reminder

Always identify the reference total before calculating. The same difference can represent very different percentages when the starting values differ.
