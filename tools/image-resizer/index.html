Image Resizer

Resize JPG, PNG or WebP images by pixels or percentage with an aspect-ratio option.

Use the tool

Choose an image to see dimensions.

How to use

  1. Select a JPG, PNG or WebP image from your device.
  2. Choose pixel or percentage mode, set the new dimensions, and keep the aspect-ratio lock enabled if you want to preserve proportions.
  3. Select Process, review the resized preview, then download the image.

Frequently asked questions

Which formats are supported?

JPG, PNG and WebP up to 20 MB.

Can I keep proportions?

Yes, the aspect-ratio option is enabled by default.

Does processing happen online?

No, resizing is performed in the browser.
