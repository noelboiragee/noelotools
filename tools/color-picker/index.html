How to use

  1. Choose a colour or edit any of the HEX, RGB or HSL fields.
  2. Copy the format you need with its Copy button.
  3. Select a recent swatch to restore a previous colour.
  4. Enter foreground and background HEX values to check WCAG contrast.

Frequently asked questions

Do all colour fields update each other?

Yes. Valid HEX, RGB or HSL edits update the picker and the other formats.

What do AA and AAA mean?

They are WCAG contrast conformance levels. Normal text thresholds are 4.5:1 for AA and 7:1 for AAA.

Are recent colours saved online?

No. Recent colours are kept only in this page session.
