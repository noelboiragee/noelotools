PDF Table to Excel

Convert a text-based PDF table, such as a bank statement, into an Excel (XLSX) or CSV file. Everything runs in your browser and your PDF is not uploaded.

Use the tool

Adjust the result
Lower it if two columns are joined. Raise it if one column is split.

Check the result against the original document before you use it. Automatic extraction can misplace columns or miss rows.

How to use

  1. Choose a PDF that has selectable text, or drop it on the box.
  2. Check the preview. If columns are joined or split, move the column spacing slider.
  3. Choose how numbers should appear, then download the XLSX or CSV file.

Frequently asked questions

Is my PDF uploaded to a server?

No. The file is read and converted in your browser. The PDF and Excel libraries load from a public CDN when the page opens, so you need an internet connection to load the page.

Does it work with scanned PDFs?

No. Scanned PDFs are images and have no text to read. They need OCR, which this tool does not include.

Why are some columns wrong?

Every bank lays out its statements differently. The tool finds columns by the position of the text, so it can be wrong on unusual layouts. Change the column spacing slider and check the preview.

Are numbers converted automatically?

Only if you choose it. By default values stay as text so nothing changes silently. Choose European or English format to get real numbers in Excel. Values with leading zeros and very long digit strings stay as text.

Why does the CSV keep the original text?

The CSV contains the values exactly as written in the PDF. Use the XLSX download if you want converted numbers.
