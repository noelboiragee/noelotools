How to use

  1. Choose a PDF that has selectable text, or drop it into the upload area.
  2. Review the preview. Adjust column spacing if columns are joined or split.
  3. Choose number and CSV settings, then download your XLSX or CSV file.

Frequently asked questions

Is my PDF uploaded to a server?

No. The file is read and converted in your browser. The PDF and Excel libraries load from a public CDN, so an internet connection is needed when the page opens.

Does it work with scanned PDFs?

No. Scanned PDFs are images and have no selectable text. They need OCR, which this tool does not include.

Why are some columns wrong?

PDF layouts vary. The tool estimates columns from text positions, so unusual layouts may need a different column spacing setting.

Are numbers converted automatically?

No. Values stay as text by default. Choose European or English number conversion if needed. Values with leading zeros and very long digit strings stay as text.

Why does the CSV keep the original text?

The CSV contains values as written in the PDF. Use the XLSX download if you want converted numbers.
