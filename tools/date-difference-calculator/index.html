EVERYDAY

Date Difference Calculator

Calculate the days, weeks and calendar months between two dates, including or excluding the end date.

Use the tool

How to use

  1. Enter the required values or choose a supported file.
  2. Select the calculation or conversion options.
  3. Press the action button and review the result. Download or copy it where available.

Frequently asked questions

Which date format is accepted?

Both dates must use DD/MM/YYYY.

Are the start and end dates included?

By default the end date is excluded; tick the option to include it.

What does months mean?

It is the number of complete calendar months between the dates.
