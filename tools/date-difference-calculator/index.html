EVERYDAY

Date Difference Calculator

Calculate the days, weeks, months, total hours, minutes and seconds between two dates.

Use the tool

How to use

  1. Choose the start date and end date using the calendar controls.
  2. Tick the checkbox if the end date should be included in the day count.
  3. Select Calculate to see the difference in days, weeks, months, hours, minutes and seconds.

Frequently asked questions

Which date format is accepted?

Choose both dates using the calendar controls.

Are the start and end dates included?

By default the end date is excluded; tick the option to include it.

What does months mean?

It is the number of complete calendar months between the dates.
