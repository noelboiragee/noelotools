Random Number Generator

Generate random integers with a secure browser random source, optional duplicates, sorting and one-click copy.

How to use

  1. Enter whole-number minimum and maximum values.
  2. Choose how many values to generate.
  3. Choose whether duplicates are allowed and whether to sort the results.
  4. Select Generate, then Copy results if needed.

Frequently asked questions

How are numbers generated?

The tool uses crypto.getRandomValues() with rejection sampling to avoid modulo bias.

What is the maximum quantity?

You can generate up to 1,000 numbers at a time.

Can I generate unique numbers?

Yes. Turn duplicates off; the selected range must contain enough integers.
