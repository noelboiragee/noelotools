Scientific Calculator

Evaluate scientific expressions with trigonometry, powers, roots, logarithms, memory keys and a calculation history.

Use the tool

Use × or * for multiplication, ÷ or / for division. Functions: sin, cos, tan, sqrt, log, ln, abs, factorial.

History

    How to use

    1. Enter an expression or use the calculator keys.
    2. Select degrees or radians for trigonometric functions.
    3. Press Calculate or Enter. Use memory keys and history to reuse previous results.
