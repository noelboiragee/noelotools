Your PDF is processed on your device. The file is not uploaded to NoeloTools. Compression libraries are loaded from public CDNs, so an internet connection is required.

Which compression mode should you use?

  • Text Preservation: Choose this for contracts, reports, forms and documents where text selection and search matter.
  • Maximum Compression: Choose this when smaller file size matters more than selectable text, such as for image-heavy scans.

Results depend on the source PDF. Text-preserving optimisation cannot guarantee a smaller file. Image-based compression can reduce clarity and removes searchable text and many interactive PDF features. Keep your original file.
