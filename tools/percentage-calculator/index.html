Percentage Calculator

Calculate a percentage of a number, find what percentage one number is of another, or calculate percentage change.

Use the tool

Use a dot for decimal values.

How to use

  1. Enter the required values or choose a supported file.
  2. Select the calculation or conversion options.
  3. Press the action button and review the result. Download or copy it where available.

Frequently asked questions

How do I calculate X% of Y?

Choose “X% of Y”, then enter the percentage and the base number.

How is percentage change calculated?

It is (new value − old value) divided by the absolute old value, multiplied by 100.

Can I use decimal values?

Yes. Enter decimal values using a dot.
