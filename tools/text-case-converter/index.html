Text Case Converter

Convert text to uppercase, lowercase, title, sentence, camelCase, snake_case and kebab-case.

Use the tool

How to use

  1. Enter the required text or choose an image file.
  2. Select the options you need.
  3. Press Convert, then use Copy output if needed.

Frequently asked questions

Which cases are included?

Seven common text and programming cases.

Does title case preserve punctuation?

Yes, the original punctuation and spaces are retained only in upper/lower/sentence modes; word-based modes normalise separators.

Can I copy the result?

Yes, use Copy output.
