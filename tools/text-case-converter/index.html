Text Case Converter

Convert text to uppercase, lowercase, title, sentence, camelCase, snake_case and kebab-case.

Use the tool

How to use

  1. Type or paste text into the input field.
  2. Choose the required format from the Case list.
  3. Select Convert, then review the output or use Copy output.

Frequently asked questions

Which cases are included?

Seven common text and programming cases.

Does title case preserve punctuation?

No. Title Case converts the text into words and joins them with single spaces, so punctuation and original separators are not preserved.

Can I copy the result?

Yes, use Copy output.
